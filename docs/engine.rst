Пакет ``minizemax.engine``
==========================

Источник пучков и sequential-трейсер. Статусы лучей: 0=ALIVE, 1=BLOCKED(апертура),
2=TIR, 3=MISS; ``stop_point``/``stop_surf`` дают точку гибели для 3D и loss-budget.
