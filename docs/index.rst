mini-Zemax — документация разработчика
======================================

Sequential optical design toy: векторный ray-tracing, параксиал, аберрации,
DLS-оптимизация, PyQt-GUI с GPU-3D. Каждая страница пакета содержит
autodoc-справочник, связи классов (mermaid) и ссылки на формулы (:eq:`snell` и т.д.).
